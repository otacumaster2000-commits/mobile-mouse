PhoneMouse v0.3 — подключение через хот-спот Windows и автопоиск

1. На Windows: Параметры -> Сеть и Интернет -> Мобильный хот-спот -> Вкл.
2. Подключи OnePlus 15 к Wi-Fi сети, которую раздаёт ноутбук.
3. Запусти Windows/Запустить PhoneMouse.bat (нужен Python 3).
4. Разреши доступ к сети в брандмауэре Windows для частных сетей. Используются UDP 45790 (поиск), TCP 45789 (мышь). Никаких настроек роутера и проброса портов не требуется.
5. В Android-приложении введи 6-значный PIN, указанный на ноутбуке, и нажми Подключить. IP вводить не надо.
6. Для обновления ранее загруженного на GitHub репозитория замени MainActivity.java, AndroidManifest.xml и, если необходимо, .github/workflows/build-apk.yml. Windows/ не обязательно загружать на GitHub, она запускается на ноутбуке.
7. Для сборки APK: GitHub -> Actions -> Build PhoneMouse APK -> Run workflow; скачать artifact app-debug.apk.

Внимание: автоматический поиск работает при разрешённом UDP broadcast между ноутбуком и телефоном. Некоторые конфигурации брандмауэра, VPN и хот-спота могут блокировать обнаружение. APK пока не тестировался на OnePlus 15. Камера не гарантирует фокусировку вплотную к столу.
