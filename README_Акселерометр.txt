PhoneMouse 0.5 — экспериментальная мышь по акселерометру

1. Windows: используй рабочую программу PhoneMouse USB из папки Windows, platform-tools должны быть установлены как раньше.
2. Android: загрузи файлы из app/ в свою ветку GitHub, запусти Actions и установи новый app-debug.apk.
3. Подключи телефон по USB, разреши USB-отладку, запусти Windows-программу.
4. Положи телефон экраном вверх на ровный стол, введи PIN и подключись.
5. Проводи по столу, подбирай чувствительность; при дрейфе нажми «СБРОС ДРЕЙФА».

ВАЖНО: акселерометр не является датчиком расстояния. При равномерной скорости/медленном движении он не определяет позицию. Возможны ложные движения и обратные рывки при остановке. Это только эксперимент, не точная замена оптической мыши.
Готовый APK не входит: для сборки GitHub Actions используй build-apk.yml.
