PhoneMouse 0.4 USB — установка

ИНТЕРНЕТ И ПРАВА АДМИНИСТРАТОРА ДЛЯ БРАНДМАУЭРА НЕ ТРЕБУЮТСЯ.
Нужны Python 3 на ноутбуке, Android SDK Platform-Tools (ADB), USB-кабель с передачей данных и USB-отладка.

1. Скачай официальные Android SDK Platform-Tools для Windows:
   https://developer.android.com/tools/releases/platform-tools
2. Распакуй папку platform-tools прямо внутрь папки Windows рядом с PhoneMouse_PC.py.
   Пример: Windows/platform-tools/adb.exe
3. На OnePlus открой Настройки -> О телефоне -> несколько раз нажми Номер сборки, чтобы включить меню разработчика. В меню Для разработчиков включи Отладку по USB (названия пунктов могут отличаться).
4. Подключи телефон к ноутбуку кабелем, подтверди запрос Разрешить USB-отладку на телефоне. Если запрос не появляется, проверь режим USB/кабель.
5. Запусти Windows/Запустить PhoneMouse.bat. Программа автоматически выполнит: adb reverse tcp:45789 tcp:45789
6. Собери Android APK из папки проекта через GitHub Actions как раньше. Установи APK.
7. На ноутбуке увидишь PIN. Введи его в Android PhoneMouse и нажми ПОДКЛЮЧИТЬ.
8. Держи USB подключённым. Wi-Fi и хот-спот не нужны.

При проблемах: открыть PowerShell в папке platform-tools и проверить `.\adb.exe devices` и `.\adb.exe reverse --list`.
USB-отладка предоставляет ноутбуку расширенный доступ к устройству: разрешай только доверенному компьютеру, отключай после тестирования.
Программа слушает только 127.0.0.1, а не входящие интерфейсы сети Windows.

ВАЖНО: сборка APK и реальная проверка соединения на OnePlus 15 не выполнялись в этой среде.
